QuakeWorld MVD Analytics API

This service parses QuakeWorld .mvd demos into structured analytics — frags, damage, weapon accuracy, positions, region control and more — over a JSON REST API.

Access requires an API key. Sign in with Discord to get one; it takes a few seconds and no email or server membership is requested — only your Discord username and id.

Sign in with Discord

Using the API

Send your key as a bearer token:

Authorization: Bearer qwmvd_…

See the API documentation for the endpoint surface, parameters and response shapes.
